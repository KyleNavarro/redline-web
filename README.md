# Redline · Sitio institucional

Sitio web institucional de **Redline Soluciones Profesionales** (Barrancabermeja, Santander), con énfasis en proyectos de energía solar.

Hecho solo con HTML, CSS y JavaScript vanilla, sin dependencias ni paso de compilación.

## Ver el sitio

Abre `index.html` en el navegador, o sirve la carpeta:

```sh
python3 -m http.server 8765
```

y visita http://localhost:8765/.

## Estructura

- `index.html`: página única
- `css/styles.css`: estilos
- `js/detector.js`: animación del detector en el hero
- `js/main.js`: navegación, estimador solar, proceso, mapa de cobertura y formulario
- `assets/`: fuentes e imágenes
- `PRODUCT.md` y `DESIGN.md`: contexto del producto y sistema visual

## Antes de publicar

- Las cifras marcadas con `*` son ilustrativas: reemplazar por datos reales.
- Las fotos de `assets/img/` son de stock: reemplazar por fotos de proyectos propios.
- Confirmar con el cliente las descripciones de servicios y los supuestos del estimador.
